# Requisitos del sistema

Use los siguientes requisitos del sistema para configurar y ejecutar sesiones de Live Hub en Adobe Learning Manager. Live Hub utiliza los mismos requisitos de hardware, sistema operativo y navegador que el entorno de clase virtual en el que se ejecuta.

Live Hub está disponible en sesiones de clase virtual y no requiere una instalación de cliente independiente.

| Categoría | Requisitos |
|---|---|
| **Navegadores de escritorio** | Versiones más recientes de Google Chrome, Mozilla Firefox, Microsoft Edge y Safari |
| **Navegadores móviles** | Chrome Mobile, Safari Mobile e Internet de Samsung |
| **Sistemas operativos** | Windows 10 o posterior, macOS 15 o posterior |
| **Resoluciones de pantalla** | 1920 × 1080, 1366 × 768, 768 × 1024 (comprimido) y 375 × 667 (móvil) |
| **Hardware de Windows** | 8 GB de RAM como mínimo, procesador de 8 núcleos, Intel® Core™ i5 o superior |
| **Hardware Mac** | RAM mínima de 16 GB, procesador de 4 núcleos, 3,2 GHz o superior |
| **Red** | Se recomienda una conexión de banda ancha estable de al menos 5 Mbps para las funciones de audio en directo, vídeo y Live Hub con tecnología de IA |

>[!NOTE]
>
>Los navegadores Linux, los dispositivos Chromebook, Firefox Mobile, Opera (escritorio y móvil), Internet Explorer 11 y las versiones más antiguas de los navegadores no son compatibles.
