# Función del administrador en la sesión de Live Hub

Como administrador de Adobe Learning Manager (ALM), puede configurar y administrar los componentes clave necesarios para impartir la formación de Live Hub. Estas funciones ayudan a optimizar las asignaciones de instructores, la configuración de cursos, la construcción de marca y la creación de informes.

Este artículo proporciona una descripción general de alto nivel de las acciones del administrador relacionadas con las sesiones de Live Hub. Para conocer los pasos y flujos de trabajo de configuración detallados, consulte los artículos vinculados de cada sección.

## Funciones de administrador para Live Hub

Como administrador, puede configurar y ejecutar la formación de Live Hub con las siguientes funciones. Seleccione un artículo vinculado para ver los pasos detallados.

| **Capacidad** | **Qué puedes hacer** | **Más información** |
|----|----|----|
| **Habilitar Live Hub** | Active Live Hub para la cuenta de Adobe Learning Manager. También puede habilitar los asistentes con tecnología de IA que ofrecen asistencia a autores e instructores durante las sesiones de Live Hub, entre los que se incluyen: <ul><li>Asistente de encuestas</li><li>Asistente de preguntas y respuestas</li><li>Asistente de supervisión de grupos de trabajo</li><li>Generador de temas de grabación</li><li>Asistente de búsqueda de instructores</li></ul> | [Habilitar característica de Live Hub](../administrators/feature-summary/enable-live-hub.md) |
| **Administrar perfiles de instructor** | <ul><li>Definir las funciones y responsabilidades del instructor</li><li>Asignar aptitudes y experiencia</li><li>Establecer preferencias de disponibilidad y enseñanza</li><li>Activar recomendaciones más inteligentes a través del buscador de instructores</li></ul> | [Agregar y administrar instructores](./instructor-management.md) |
| **Agregar aptitudes en bloque** | <ul><li>Adición masiva de aptitudes</li><li>Organizar y actualizar conjuntos de habilidades</li><li>Adaptar las aptitudes a los requisitos del curso</li></ul> | [Crear y modificar aptitudes y niveles](../administrators/feature-summary/skills-levels.md#add-skills-in-bulk) |
| **Administrar vacaciones** | <ul><li>Añada una sola festividad o importe varias a la vez cargando un archivo CSV</li><li>Establezca una fecha, un nombre y una descripción opcional para cada festividad</li><li>Revisar, buscar y filtrar días no laborables o festividades en las pestañas Todo, Próximo y Pasado</li><li>Mantener un calendario de vacaciones coherente en toda la cuenta</li></ul> | [Administrar vacaciones](./manage-holidays.md) |
| **Configurar temas de color y marca** | <ul><li>Aplicar temas de color</li><li>Mantener una identidad visual coherente entre sesiones</li><li>Mejora la experiencia del alumno con entornos de marca</li></ul> | [Temas de color](../administrators/feature-summary/themes.md#color-themes) |
