# Función de los autores en la sesión de Live Hub

Como autor en Adobe Learning Manager, puede crear y administrar cursos de clase virtual que utilizan Live Hub para impartir formación en directo dirigida por un instructor. Configure el curso, configure la sesión, asigne instructores y publíquelo para que la sesión esté lista para ejecutarse.

Este artículo describe lo que hace un autor cuando trabaja con Live Hub.

## Qué pueden hacer los autores

Como autor, es responsable de las siguientes tareas al crear un curso de Live Hub.

### Crear cursos de Live Hub

Los autores pueden crear cursos de Live Hub durante el flujo de trabajo de creación de cursos. Puede realizar lo siguiente:

* Añada un módulo de clase virtual al curso.
* Elija Live Hub como las herramientas de formación virtual en directo.
* Define los detalles de la sesión, como el título, la descripción y la duración.

### Configurar detalles de la sesión

Los autores pueden definir cómo se llevará a cabo la sesión de Live Hub. Puede realizar lo siguiente:

* Establecer fecha, hora y zona horaria
* Configurar la duración de sesión

### Utilice el Finder del instructor para asignar instructores

Utilice el buscador de instructores para buscar y asignar instructores en función del tipo de curso. Puede realizar lo siguiente:

* Obtén recomendaciones de instructores basadas en IA y en los requisitos del curso, las aptitudes y la disponibilidad.
* Seleccione uno o más instructores cualificados para la sesión.
* Acelera la configuración de cursos con recomendaciones inteligentes y una asignación de instructores simplificada.

### Publish y gestión de cursos

Una vez configurado, los autores pueden finalizar y administrar la entrega del curso. Puede realizar lo siguiente:

* Publish el curso para alumnos
* Actualizar los detalles de la sesión si es necesario
* Administrar la estructura y los módulos del curso

Vea [Crear una sesión de Live Hub](./create-a-live-hub-session.md) para obtener más información.
