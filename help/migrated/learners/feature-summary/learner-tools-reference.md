# Herramientas del alumno para el servidor de Protocolo de contexto de modelo

Cada capacidad se ejecuta como alumno que ha iniciado sesión después de que el alumno se conecte. Una solicitud devuelve solo lo que el alumno puede acceder en Adobe Learning Manager. Consulta [Conectar tu cliente de IA](/help/migrated/learners/feature-summary/connect-ai-client-to-alm-learner.md) para obtener más información.

## Capacidades del alumno

| **Capacidad** | **Qué pueden hacer los alumnos** | **Ejemplo de solicitud** |
|----|----|----|
| Buscar contenido de aprendizaje | Buscar cursos, certificaciones y rutas de aprendizaje | ¿Qué cursos de liderazgo hay disponibles? |
| Ver inscripciones | Comprobar las inscripciones y el aprendizaje debido | ¿Cuáles de mis cursos están a punto de caducar? |
| Haz preguntas de aprendizaje | Obtén respuestas del contenido de aprendizaje | ¿Qué significa la gestión de riesgos de la cadena de suministro en FedRAMP? |
| Generación de rutas de aprendizaje | Crear rutas de aprendizaje personalizadas | Ayúdame a encontrar cursos para mejorar las habilidades en la administración de proyectos. |
| Guardado de rutas de aprendizaje | Guardar rutas de aprendizaje generadas | Guarda esta ruta de aprendizaje. |

## Herramientas de MCP compatibles

El servidor MCP del Asistente del alumno expone las siguientes herramientas de aprendizaje.

| **Herramienta MCP** | **Propósito** | **Admite capacidad** |
|----|----|----|
| Buscar | Buscar contenido de aprendizaje disponible | Buscar contenido de aprendizaje |
| Obtener inscripción | Recuperar información de inscripción de alumnos | Ver inscripciones |
| Agente de respuestas | Respuesta a preguntas mediante contenido de aprendizaje | Haz preguntas de aprendizaje |
| Obtener usuario | Identificar al alumno que ha iniciado sesión para cada solicitud | Todas las funciones |
| Obtener objeto de aprendizaje | Recuperar detalles de un objeto de aprendizaje, como la descripción y la duración | Buscar contenido de aprendizaje, Ver inscripciones |
| Generar ruta de aprendizaje | Creación de rutas de aprendizaje recomendadas | Generación de rutas de aprendizaje |
| Guardar ruta de aprendizaje | Guardar rutas de aprendizaje generadas | Guardado de rutas de aprendizaje |

>[!IMPORTANT]
>
>Los nombres de las herramientas se muestran como referencia y pueden variar dependiendo de la implementación del cliente.
