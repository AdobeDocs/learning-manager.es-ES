# Mensajes de ejemplo para alumnos de Adobe Learning Manager

Primero tienes que conectar tu cliente de IA. Ver [Conectar tu cliente de IA](/help/migrated/learners/feature-summary/connect-ai-client-to-alm-learner.md). Cada mensaje se asigna a una herramienta en la referencia de [herramientas del alumno.](/help/migrated/learners/feature-summary/learner-tools-reference.md)

## Inscripciones

| **Mensaje** | **Herramienta** |
|------------------------------------------|----------------|
| ¿En qué cursos estoy inscrito? | Obtener inscripción |
| ¿Cuáles de mis cursos están a punto de caducar? | Obtener inscripción |

## Buscar

| **Mensaje** | **Herramienta** |
|-----------------------------------------|----------|
| ¿Qué cursos de liderazgo hay disponibles? | Buscar |
| Mostrar la formación en seguridad disponible para mí. | Buscar |
