# Conecta tu cliente de IA a Adobe Learning Manager

El administrador de integración debe configurar primero el conector. Si no aparece ningún conector de Adobe Learning Manager, póngase en contacto con el administrador. **El cliente solo está disponible para el nivel Adobe Learning Manager Ultimate**.

Los administradores pueden hacer referencia a [Agregar Adobe Learning Manager a su cliente de inteligencia artificial.](/help/migrated/administrators/feature-summary/add-alm-to-ai-client.md)

1. Abra el cliente de IA de su organización, como Claude o ChatGPT Enterprise.
2. Busque el conector de Adobe Learning Manager en la lista de conectores.
3. Seleccione **Conectar**.
4. Inicie sesión con su identidad de empresa cuando se le solicite.
5. Haz una pregunta sobre tu aprendizaje. Para obtener ideas, vea **solicitudes de muestra para alumnos**.

>[!NOTE]
>
>Inicia sesión una vez. Las solicitudes se ejecutan con sus propios permisos, de modo que solo ve a lo que puede acceder en Adobe Learning Manager.

## Resolución de problemas

**No se encuentra el conector**

Pida al administrador que habilite el conector.

**El cliente de inteligencia artificial no recuerda tu pregunta anterior**

Cada solicitud se trata como nueva. Que una conversación continúe depende de tu cliente de IA. Repita los detalles en la siguiente pregunta.

**El cliente de AI no llama al conector de Adobe Learning Manager**

Asigne un nombre a lo que desee en la pregunta, como las inscripciones o un tema del curso.
