# Administrar y responder a comentarios

Si eres el autor, puedes usar el panel **Comentarios** en tu proyecto para ver los comentarios y responder a ellos.

1. Seleccione **Comentarios** en la barra de herramientas superior. Se abre el panel **Comentarios**, que muestra todos los comentarios del revisor.

   ![](../assets/63_owner_in_app_comments_panel_mention_comment.png)

2. Seleccione cualquier comentario para verlo en contexto en el lienzo.

   ![](../assets/64_comment_in_context_on_canvas.png)

3. Seleccione el icono de marca de verificación para marcar un comentario como resuelto o el icono **Más opciones** para editarlo o eliminarlo.

   ![](../assets/65_comment_resolve_checkmark_delete_menu.png)

4. Guarde el curso actualizado.

5. Selecciona **Compartir** para actualizar el vínculo de revisión, de modo que los revisores vean la versión más reciente.
