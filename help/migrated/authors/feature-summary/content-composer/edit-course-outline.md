# Editar el esquema del curso

    ![](../assets/10_outline_tab_generated_lessons_topics_updated.png)

Adobe Learning Manager Content Composer genera una estructura de lección y tema a partir del resumen y el archivo de origen. El esquema aparece en el lienzo y muestra todas las lecciones y sus temas.

**Nota:** La edición de esquemas es actualmente una conversación en la versión beta. No se puede seleccionar una lección o tema en el lienzo para cambiarle el nombre o reordenarlo. Escriba el cambio como una solicitud en un idioma sencillo en el panel de chat.

El asistente trabaja conversacionalmente. Puede expresar las solicitudes con sus propias palabras. Estos son algunos ejemplos de lo que puede hacer:

| **Acción** | **Ejemplo de solicitud** |
|--------------------------|---------------------------------------------------------------------------|
| Cambiar el nombre de una lección o tema | &quot;Cambiar el nombre de la Lección 1 a &#39;Cómo funciona la suplantación de identidad&#39;&quot; |
| Agregar una lección o un tema | &quot;Agregar un tema a la Lección 2 sobre suplantación de identidad de código QR&quot; |
| Eliminar una lección o un tema | &quot;Quitar tema 1.3&quot; |
| Dividir una lección | &quot;Dividir la lección 3 en dos. Uno para filtros de spam, otro para administración de parches&quot; |
| Combinar lecciones | &quot;Combinar las lecciones 3 y 4 en una sola lección&quot; |
| Regenerar el contorno | &quot;Regenera con más énfasis en la higiene de las contraseñas&quot; |

Utilice solicitudes en lenguaje sencillo en el panel de chat para modificar lecciones, temas o la estructura de esquema completa.

La jerarquía del esquema se ha fijado como Lecciones > Temas. No se pueden crear subtemas ni estructuras de tres niveles.

Cuando el esquema parezca correcto, selecciona **Generar curso** en la barra de herramientas superior.
