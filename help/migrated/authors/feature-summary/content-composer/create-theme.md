# Crear un tema

Hay dos formas de crear un tema personalizado, las cuales añaden el resultado a tu lista de temas **Personalizados**:

- **Generar desde cero** usando la opción **Crear** de la barra de herramientas: configura la paleta de colores, las fuentes y otras propiedades y, a continuación, **guarda como nuevo**.

- **Importar un archivo JSON personalizado**: exporta un tema existente como JSON, edítalo en un editor de texto o código y luego impórtalo de nuevo.

**¿Necesitas más control?**

Para obtener tipografía por elemento (nombres de lecciones, nombres de temas, encabezados de bloque, subtítulos), personalización de nivel de token de color y acceso completo al esquema JSON, el tipo de control que normalmente desea un equipo de plataforma o marca, consulte [Personalización avanzada de temas](advanced-theme-customization.md).

## Crear un tema desde cero

1. Seleccione **Crear** en la barra de herramientas para abrir el panel **Temas del curso**.
   ![](../assets/44_course_themes_create_button_updated.png)

2. Configure la paleta de colores, las fuentes y otras propiedades del tema según sea necesario.
   ![](../assets/45_create_theme_panel_name_palette_fonts_updated.png)

3. Selecciona **Guardar como nuevo** para agregar el tema a tu lista de temas **Personalizados**.
   ![](../assets/46_custom_themes_list_new_theme_added_updated.png)

## Crear un tema importando JSON

1. Seleccione **Temas** en la barra de herramientas para abrir el panel **Temas del curso**.

2. Pase el ratón sobre el tema que desee usar como base y seleccione **Exportar** para descargarlo como archivo JSON.

3. Abra el archivo JSON en un editor de texto o de código y actualice sus propiedades, como el radio, el espaciado, la paleta de colores o las fuentes.

4. Guarde el archivo JSON.

5. En Content Composer, seleccione **Importar** en el panel **Temas del curso**.

6. Elija el archivo JSON actualizado en el equipo.

7. Selecciona **Guardar como nuevo** para agregar el tema a tu lista de temas **Personalizados**.
