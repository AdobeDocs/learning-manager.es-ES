# Editar el texto del curso

![](../assets/15_lesson_image_text_block_fall_prevention_updated.png)

Seleccione cualquier elemento de texto para colocar el cursor en su interior. En la parte inferior del lienzo aparece una barra de herramientas de formato con controles de negrita, cursiva, subrayado, tachado, vínculo, alineación y lista.

>[!NOTE]
>
>Los nombres de temas y de lecciones forman parte de la estructura del esquema. Para cambiarles el nombre después de generar el curso, pregunte al asistente: &quot;Cambie el nombre de la Lección 2 a &#39;Higiene de contraseñas&#39;.&quot; No puede cambiarles el nombre seleccionando un encabezado en el Editor de cursos.
