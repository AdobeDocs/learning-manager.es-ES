# Revisar el curso generado

![](../assets/11_course_view_generated_topic_content_updated.png)

Adobe Learning Manager Content Composer genera el curso completo con texto, imágenes, comprobaciones de conocimientos y una prueba en un solo pase. El editor de **Course** se abre automáticamente al finalizar la generación.

El panel izquierdo muestra la navegación por lecciones y temas. El lienzo muestra el contenido del tema seleccionado. El panel de chat permanece abierto para la edición de conversaciones.

>[!CAUTION]
>
>Revisar todo el contenido generado antes de compartir o publicar. La salida de IA puede variar de una generación a otra y puede contener imprecisiones. Se requiere la revisión del autor antes de la distribución.
