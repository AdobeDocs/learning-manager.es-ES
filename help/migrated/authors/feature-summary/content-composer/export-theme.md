# Exportar un tema

Exporte un tema como archivo JSON para personalizarlo fuera de Content Composer o compartirlo con otros autores.

1. Seleccione **Temas** en la barra de herramientas para abrir el panel **Temas del curso**.

2. Pase el ratón sobre el tema que desea exportar y seleccione el icono **Exportar**.
   ![](../assets/47_export_theme_save_as_json_dialog_updated.png)

3. En el cuadro de diálogo que aparece, elija una ubicación, escriba un **nombre de archivo.**
