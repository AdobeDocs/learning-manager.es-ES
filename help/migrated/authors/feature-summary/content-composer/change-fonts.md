# Cambiar fuentes

Actualiza las fuentes de encabezado y cuerpo para que se ajusten mejor a tu contenido o marca.

1. Selecciona **Temas** en la barra de herramientas, coloca el cursor sobre el tema aplicado y selecciona **Editar**. Se abre el panel **Editar tema**, que muestra la paleta de colores y las fuentes del tema.

   ![](../assets/35_course_themes_list_edit_icon_updated.png)

2. En **Fuentes**, seleccione el menú desplegable **Títulos** y elija una fuente para todos los títulos del curso. Por ejemplo, seleccione **Equipo**.

   ![](../assets/36_edit_theme_headings_font_dropdown_updated.png)

3. Seleccione el menú desplegable **Cuerpo** y elija una fuente para el texto independiente del curso. Por ejemplo, seleccione **DM Sans**.

   ![](../assets//37_edit_theme_body_font_dropdown_updated.png)

4. Selecciona **Guardar** para sobrescribir el tema existente con tus cambios o **Guardar** **como nuevo** para crear un nuevo tema personalizado sin modificar el original.

   ![](../assets/38_edit_theme_full_panel_header_logo_updated.png)

>[!NOTE]
>
>Los temas predeterminados no se pueden editar directamente. Para personalizar un tema predeterminado, edítelo y, a continuación, seleccione Guardar como nuevo para crear un tema personalizado basado en el original.
