# Crear un juego de roles mediante una plantilla de Entrenador virtual

Publish crea un escenario de Virtual Coach creado previamente en cuestión de minutos a partir de una plantilla en lugar de crear un juego de roles desde cero.

Las secciones **Destacado** y **Plantillas disponibles** de Virtual Coach contienen una biblioteca de escenarios de juego de roles prediseñados que abarcan situaciones de ventas, liderazgo y evaluación de habilidades. El uso de una plantilla es la forma más rápida de crear un juego de roles: el personaje, la apertura de la conversación, los temas y la puntuación ya están configurados, y puedes publicar inmediatamente o personalizar cualquier detalle antes de publicar.

Las plantillas se organizan por dominio, tipo de simulación e idioma. Usa los filtros para reducir la lista por tipo de interacción, como **Conversación de voz** o **Práctica de cámara web**, o busca por palabra clave para encontrar un escenario más cercano a tu caso de uso.

>[!TIP]
>
>La selección de una plantilla no le bloquea en su configuración predeterminada. Todos los campos, incluidos el fondo personal, los temas, las ponderaciones de puntuación y la apertura de la conversación, se pueden editar después de seleccionar la plantilla. Trata las plantillas como un punto de partida, no como un diseño final. Para obtener una explicación completa de cada campo configurable, consulte [crear y publicar un juego de roles de Entrenador virtual](/help/migrated/authors/feature-summary/virtual-coach/create-publish-virtual-coach-role-play.md).


1. Inicie sesión en Adobe Learning Manager como autor.
2. Seleccione **Entrenador virtual** en el panel de navegación izquierdo.
3. Seleccione **Crear ahora**.
4. Explora la sección **Plantillas disponibles** o usa la barra **Buscar** y los filtros de dominio, tipo de simulación e idioma para encontrar una plantilla que coincida con tu escenario.

   ![](/help/migrated/authors/feature-summary/assets/virtual-coach25.png)
5. Seleccione el mosaico de la plantilla para abrirlo. Revise la configuración de persona, temas y puntuación.

   ![](/help/migrated/authors/feature-summary/assets/virtual_coach17.png)
   *Revise el contexto de conversación y el fondo personal rellenados previamente antes de decidir si desea personalizar la plantilla.*

6. Para usar la plantilla tal cual, selecciona **Publish**. Para personalizarla primero, seleccione cualquier sección y edite los campos relevantes antes de publicar.

Una vez publicado, el juego de roles se agrega a la **biblioteca de contenido** y está listo para agregarse a una ayuda de trabajo y asignarse a un curso. Consulta [añadir un juego de roles de entrenador virtual a un curso](/help/migrated/authors/feature-summary/virtual-coach/add-virtual-coach-role-play-to-course.md) para obtener esos pasos, o [practicar un juego de roles con entrenador virtual](/help/migrated/learners/feature-summary/virtual-coach/practice-role-play-with-virtual-coach.md) para ver la experiencia del alumno.
